## 子育ての悩み相談 合成対話データセット（3,000件）
本リポジトリは、子育てに関する悩み相談を想定した合成対話データセットを公開するものです。

## 概要

データセット統計情報
```
{
  "total_simulations": 3000,
  "dialogue_turns": 13.0,
  "user_average_utterance_length": 48.8,
  "assistant_average_utterance_length": 136.18
}
```

- total_simulations: 対話数
- dialogue_turns: 1対話あたりのターン数
- user_average_utterance_length: ユーザ発話の平均文字数
- assistant_average_utterance_length: システム発話の平均文字数

データ形式（例）
```
{
  "question_id": 1,
  "challenge": "子どもに金銭的なご褒美で買収するのは良い考えですか？",
  "basic_information": "- 性別: 女性  \n- 年齢: 35歳前後  \n- 家族関係や婚姻状態: 既婚で子どもがいる（親）  ",
  "background": "子どもの勉強嫌いが顕在化したのは、先月のテスト結果が思わしくなかったことが原因です。・・・",
  "tips": "１：宿題終わりに好きな音楽5分だけ流す  \n２：毎日小さな達成シールを貼る  \n３：学んだことを親子でクイズに",
  "dialogue": [
    {
      "role": "assistant",
      "content": "こんにちは！子育てのことで気になることがあれば、どんなことでも話してみてね。"
    },
    {
      "role": "user",
      "content": "先月のテストで点数が低くなり、息子がやる気を失っているので、金銭で宿題を促すべきかどうか迷っています。"
    }
  ]
}
```

※ 実際のフィールド構成はデータをご確認ください。
